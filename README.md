# 💸 N-Pang 정산

모임 비용을 **기여도(%) 기반**으로 나눠 각자 낼 금액을 계산하고, **링크 하나로 공유**하는 웹앱.

🔗 **라이브: https://xeminix.github.io/N-Pang/**

순수 HTML/CSS/JS 단일 파일. 빌드 없음, 의존성 없음, 서버 없음.

---

## 기능

- **참가자 관리** — 이름을 칩으로 추가/삭제
- **회차별 입력** — 장소/내용 + 총 금액(원) + 각자 기여도(%)
- **기여도 합계 검증** — 회차마다 합이 100%인지 실시간 표시, `⚖️ 균등 분배(n빵)` 버튼
- **자동 정산 계산** — 각자 = `Σ(회차금액 × 기여도%)`, **100원 단위 절사**(엑셀 `TRUNC(...,-2)`와 동일)
- **결과 링크 공유** — 입력 데이터를 URL 해시(base64)에 담아 공유. 받는 사람은 주소만 열면 결과를 봄 (서버 불필요)
- **입금처** — 계좌/카카오·토스, 결과 화면에서 원터치 복사
- **마지막 입력 자동 저장**(localStorage) + **전체 초기화**
- **모바일 반응형** — 폰에서 카톡 링크로 바로 확인

## 사용법

1. **편집 탭**에서 정산 제목 → 참가자 추가 → 회차별 금액·기여도 입력 → 입금처 입력
2. **정산 결과 보기** → 1인당 금액 확인
3. **🔗 결과 링크 복사** → 카톡 등으로 공유. 받는 사람은 링크만 열면 각자 낼 금액 + 입금처를 봄

## 정산 로직

각 회차 `i`의 총금액을 `Kᵢ`, 참가자 `j`의 회차 `i` 기여도를 `pᵢⱼ(%)`라 할 때:

```
참가자 j가 낼 금액 = TRUNC( Σᵢ ( Kᵢ × pᵢⱼ / 100 ), 100원 )
```

- 한 회차의 기여도 합은 100%가 되어야 함 (UI에서 검증)
- 절사는 100원 미만 버림 (toward zero), 엑셀 원본 `TRUNC(...,-2)`와 일치

## 로컬 실행

서버 필요 없음. `index.html`을 브라우저로 열면 끝.

```bash
open index.html          # macOS
# 또는 정적 서버
python3 -m http.server 8000
```

## 기술

- 단일 `index.html` (HTML + CSS + Vanilla JS), 외부 라이브러리 0
- 데이터는 **URL 해시**와 **localStorage**에만 존재 — 서버/DB 없음
- 배포: GitHub Pages (`master` 브랜치 / root)

## 개인정보 / 보안

- 실제 계좌번호·이름 등은 **저장소에 커밋되지 않음.** 사용자가 입력한 데이터는 링크에만 담김
- 공유 링크에는 입력한 내용이 base64로 인코딩되어 들어가므로, **링크를 받은 사람은 그 내용을 볼 수 있음** (민감정보는 신뢰하는 상대에게만 공유)
- 원본 정산 엑셀(`Ref-docs/`)은 `.gitignore`로 제외됨
